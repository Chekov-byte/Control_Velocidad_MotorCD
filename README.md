# Control_Velocidad_MotorCD
Aquí encontrarás el código para realizar el control de velocidad de un motor de CD. Hay dos archivos, el archivo Arduino para programar la placa UNO y obtener los datos; el otro archivo es un Script de Matlab para graficar y analizar los datos. 
El esquema de control de velocidad contempla un perfil de velocidad deseada y un perfil de perturbación de voltaje. El objetivo de estos perfiles es verificar el comportamiento de las acciones de control.
